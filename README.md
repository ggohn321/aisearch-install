# ไอเสริฐ: ตัวติดตั้ง

โปรแกรมค้นฟุตของทีม 8Story เปิดหน้าติดตั้ง: https://ggohn321.github.io/aisearch-install/

- Windows: [AiSearch-Setup.exe](https://github.com/ggohn321/aisearch-install/releases/latest/download/AiSearch-Setup.exe)
- Mac: เปิด Terminal แล้ววาง
  `curl -fsSL https://github.com/ggohn321/aisearch-install/releases/latest/download/install-mac.command | bash`

ใช้งานได้เมื่อมี Google Drive for desktop ที่เห็นโฟลเดอร์ All 8Story (โก๋แชร์ให้)
