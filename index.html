ติดตั้ง 8Story HQ

โปรแกรมของทีม 8Story: ค้นฟุตทุกแบรนด์แล้วลากลง CapCut ได้เลย ห้องทำงาน Guideline และงานของแต่ละตำแหน่ง ติดตั้งครั้งเดียว หลังจากนั้นโปรแกรมอัปเดตตัวเอง

เปิดลิงก์นี้บนคอม (Windows หรือ Mac) 8Story HQ ติดตั้งบนมือถือไม่ได้

ก่อนกดติดตั้ง
  • มีแอป Google Drive for desktop ล็อกอินบัญชีที่โก๋แชร์โฟลเดอร์ All 8Story ให้
  • เพิ่มทางลัด All 8Story ไว้ในไดรฟ์ของฉัน โปรแกรมดึงฟุตจากตรงนั้น

Windows

เครื่องนี้
ติดตั้งบน Windows 8Story-HQ-Setup.exe · 112 MB
  1. เปิดไฟล์ที่โหลดมา (มุมขวาบนของเบราว์เซอร์)
  2. ถ้ามีหน้าต่างฟ้า "Windows protected your PC" กด More info แล้ว Run anyway
  3. 8Story HQ ติดตั้งและเปิดเอง มีไอคอน 8Story HQ บนเดสก์ท็อป

Mac

เครื่องนี้
กดแล้วคำสั่งติดตั้งถูกคัดลอกไว้
  1. กด ⌘ Space พิมพ์ Terminal กด Return
  2. กด ⌘ V แล้ว Return
  3. 8Story HQ ติดตั้งและเปิดเอง (อยู่ในโฟลเดอร์ Applications ในโฮม) ครั้งแรก Mac ถามสิทธิ์เข้าถึงโฟลเดอร์ กด Allow

    

  


  

    
ติดตั้งแล้วไม่ต้องโหลดใหม่ เวลาโก๋อัปเดต 8Story HQ จะขึ้นป้ายบอกและอัปเดตเอง · ใครลงไอเสริฐไว้แล้วไม่ต้องลงใหม่ (โปรแกรมเดียวกัน ไอคอนเปลี่ยนชื่อเป็น 8Story HQ เอง)

    
ปุ่มไม่ทำงาน เปิดหน้าไฟล์ติดตั้งบน GitHub แล้วโหลดไฟล์เอง
